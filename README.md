## Workplace Inspection app

Impact Rank's HACCP, workplace safety (OSHP-06.02) and ISO 14001 environmental inspections in one app.

- [Open the app](https://script.google.com/macros/s/AKfycbytx5uxMD3vGso1nbUTJF_AyhCjzks9WrDYaASZtYm28EQXDnzZxfOFKYJcoKPZxHJs/exec): the live app. Records are saved in the company's Google Sheet; you need a login.
- [Try the demo](https://zuraidah94.github.io/public-doc/inspection-app/): the same app with example users (log in as `admin`, password `123`). It saves only in your own browser.
- [How it works](inspection-app/README.md): the forms it covers, where records are saved and how to set it up.
