# 3D upload folder

Drop the free Quaternius `.glb` files here: **Add file → Upload files** on this page.

- Universal Base Characters: the character `.glb` files (men, women, teens)
- Universal Animation Library: the animation `.glb` file(s)

Both packs are CC0 (free to use and share). Claude picks them up from here and wires them into
`rumah-kita/edisi-lukisan-tangan-hf/` as 3D people.
