# Claude Prompt Book

Ready-to-copy prompts for Claude, in English and Bahasa Melayu. Copied from the Claude artifact "Zuraidah's Prompt Book" (Doc PB-01, Rev 1, 22 Oct 2026).

## Open it

- [Open the prompt book](https://zuraidah94.github.io/public-doc/prompt-book/)

Each prompt has a **Copy prompt** button and an **EN / BM** switch. Words in `[brackets]` are yours to fill in. Search with the box at the top, or jump to a chapter by adding its id to the link, for example `.../prompt-book/#game`.

## The 6-part prompt formula

Every prompt in the book follows the same shape:

| Part | What it says |
| --- | --- |
| Role | Who Claude should act as |
| Task | The one job, with a measurable target |
| Input | What you are giving it: files, notes, links, month |
| Output | File type, format, language, length |
| Rules | What must or must not happen |
| Checkpoint | Where Claude stops and shows you first |
